# 光源追跡ロボットシミュレーター

光源追跡ロボットの動きを再現したシミュレーターです。仮想ライトを使って光源追跡ロボットをソフトウェア上で動かすことができます。

## ダウンロード

Windows環境で利用するためのインストーラーは、以下のリンクからダウンロードできます。
>※Windows11でのみ動作確認済

[光源追跡ロボットシミュレーター(インストーラー)をダウンロード](https://github.com/nit-robotvolunteer/kougentuiseki/releases/download/v1.0/LTRS_Setup.exe)

## 実行時の注意
本ソフトウェアはデジタル署名を行っていないため、実行時に「ユーザーアカウント制御」による警告画面「この不明な発行元からのアプリがデバイスに変更を加えることを許可しますか」が表示されることがあります。
> その場合「はい」を選択してください。

## 使い方
1. 上記リンクから `LTRS_Setup.exe` をダウンロードします。
2. インストーラーを実行し、画面の指示に従ってインストールを完了させてください。
3. デスクトップに作成されたショートカットから起動できます。
